## Read me



### **Multiplication Table Flask Project**



I made this project while learning Flask. This is a simple Flask project that takes a number from the user and displays its multiplication table from 1 to 10.



##### **Technologies Used**



* Python
* Flask
* HTML
* CSS
* Jinja2



##### **How It Works**



1.Enter a number in the input box.

2.Click the SEND button.

3.The number is sent to Flask using a POST request.

4.Python creates the multiplication table.

5.Jinja displays the results on the webpage.



##### What I learned



I learned how to connect things like HTML, Python, and CSS, how they connect to each other, and how to send data from here to there. I understood POST and GET, learned new syntax, and learned Jinja. It has a little different syntax Overall, this was a great project.
